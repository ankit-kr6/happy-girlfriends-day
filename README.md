# Happy Girlfriend Day — for Bunny 🐰

A two-page site: `index.html` (envelope you click to open) → `next.html` (letter, reasons, photos, bunny, music).

## To personalize before sending

1. **Photos** — drop 3 images into the `assets` folder named exactly:
   - `assets/photo1.jpg`
   - `assets/photo2.jpg`
   - `assets/photo3.jpg`
   They'll auto-fill the gallery slots (any placeholder without a matching file just stays as a dashed box, so it's fine if you only add 1 or 2).

2. **Song** — add your own audio file as `assets/song.mp3` (any song you both like). The music button (bottom-right ♪) will play it once it's there.

3. **Text** — everything is plain Hinglish inside `next.html`. Search for the `<div class="letter">` block and the 5 flip-cards to tweak wording, add inside jokes, or extend the reasons list.

## To open it locally
Just double-click `index.html` — it opens in your browser, no server needed.

## To send it to her as a link (recommended)
Easiest free option is GitHub Pages:
1. Create a new GitHub repo, upload all these files (keep the folder structure).
2. Repo → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
3. You'll get a link like `https://yourusername.github.io/reponame/` — send her that.

Enjoy, and happy girlfriend day 🤍
